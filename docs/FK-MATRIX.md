## Rules

- A resolved FK is any `pg_constraint` row with `contype = 'f'` in `public`.
- A deferred candidate must be a UUID `_id`/`_by` column with no resolved FK and a target table that exists in this schema.
- Polymorphic references, array columns, external identifiers, correlation IDs, and `events.event_id` are never candidates.
- A missing target table means no candidate is invented; it is listed under non-FK identifiers with the reason.
